Decware Order Tracker

Welcome to the Decware Order Tracking System

This application allows you to track the status of your Decware audio equipment orders.

The system is deployed on Heroku and provides a RESTful API for accessing order information.

Available API Endpoints

  • Order Records: View Order Records

    Access information about all orders in the system.

  • Status Metrics: View Status Metrics

    Get metrics about orders grouped by status.

  • Status History: View Status History

    View the history of status changes for orders.

Search Functionality

You can search for specific orders by adding query parameters to the Order Records endpoint:

  • /api/orders/records/?customer_name=Smith - Search by customer name
  • /api/orders/records/?model=ZMA - Search by model
  • /api/orders/records/?status=TESTING - Filter by status
